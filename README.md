# 🌊 VocaFlow (보카플로우) - 스마트 영어 단어 학습 앱

> **에빙하우스 망각 곡선 간격 반복(SRS) 알고리즘**과 **원어민 음성(TTS)**, **AI 발음 평가(STT)**가 탑재된 모바일 퍼스트 반응형 PWA 영어 단어 암기장입니다.

---

## ✨ 핵심 기능

1. **에빙하우스 망각 곡선 & 간격 반복(SM-2) 시스템**
   - 단어별 숙련도 단계(Level 0~6) 및 최적의 복습 타이밍 자동 스케줄링
   - `다시 보기(1분)`, `어려움(10분)`, `알아요(1일)`, `쉬워요(4일)` 평가 버튼을 통한 맞춤형 간격 계산
   - 대시보드에서 오늘 복습해야 할 단어를 한눈에 확인하고 원클릭 복습

2. **3D 플래시카드 & 터치 스와이프 제스처**
   - 앞면: 영단어, 발음 기호(IPA), 음성 듣기, 마이크 발음 테스트
   - 뒷면 (터치 시 3D 회전): 한글 뜻, 영영 정의, 실전 예문 및 해석, 어원 연상 꿀팁
   - 모바일 스와이프 제스처: 왼쪽으로 밀면 **다시 보기**, 오른쪽으로 밀면 **기억 완료**

3. **원어민 발음 듣기(TTS) & 실시간 발음 평가(STT)**
   - 🔊 **TTS 발음 듣기**: 미국식(US) / 영국식(UK) 억양 및 0.75x~1.25x 속도 조절
   - 🎙️ **STT 발음 채점**: 마이크로 발음하면 음성을 인식하고 Levenshtein 유사도 알고리즘으로 0~100점 정확도 채점 및 피드백

4. **4가지 스마트 퀴즈 챌린지**
   - 🎯 **뜻 맞히기**: 객관식 4지선다 퀴즈
   - 🎧 **리스닝 퀴즈**: 원어민 발음 소리를 듣고 올바른 단어 선택
   - ⌨️ **스펠링 채우기**: 한글 뜻과 예문을 보고 철자 직접 타이핑
   - 🗣️ **발음 말하기 퀴즈**: 마이크로 직접 말해 통과하는 스피킹 테스트

5. **단어장 관리 및 데이터 보존**
   - 나만의 단어 추가, 카테고리별 분류, 즐겨찾기(⭐)
   - 실시간 검색(단어, 뜻, 예문)
   - `localStorage` 자동 저장 및 JSON 백업/복원 기능 제공

6. **모바일 PWA (설치형 웹앱) 지원**
   - 별도의 앱스토어 설치 없이 스마트폰 홈 화면에 '앱으로 추가'하여 네이티브 앱처럼 풀스크린 구동

---

## 🚀 실행 방법

### 방법 1: 원클릭 실행 (추천)
폴더 안의 **`start.bat`** 파일을 더블 클릭하면 로컬 서버가 시작되며 브라우저가 자동으로 열립니다 (`http://localhost:5050/`).

### 방법 2: 브라우저로 바로 열기
**`index.html`** 파일을 더블 클릭하여 Chrome 또는 Edge 브라우저에서 바로 열 수 있습니다.

---

## 📱 스마트폰에 앱으로 설치하는 방법 (PWA)

- **iPhone / iPad (Safari)**:
  1. Safari 브라우저에서 사이트 접속
  2. 하단 중앙의 **공유 아이콘(⎋)** 터치
  3. 메뉴에서 **[홈 화면에 추가]** 선택
- **Android (Chrome)**:
  1. Chrome 브라우저에서 사이트 접속
  2. 우측 상단 **더보기 메뉴(⋮)** 터치
  3. **[앱 설치]** 또는 **[홈 화면에 추가]** 선택

## 📁 파일 구조

```
├── index.html          # 메인 HTML 마크업 (모바일 셸 레이아웃 및 5개 탭)
├── styles.css          # 모던 반응형 스타일시트 (다크모드, 3D 플립, 애니메이션)
├── manifest.json       # PWA 매니페스트 (홈화면 설치 설정)
├── sw.js               # 오프라인 캐싱 Service Worker
├── icon.svg            # 고해상도 앱 아이콘
├── server.ps1          # 무설치 로컬 웹 서버 스크립트
├── start.bat           # 원클릭 실행 배치 파일
├── data/
│   └── words.js        # 풍부한 초기 단어 데이터 (기초, 비즈니스, 회화, 고급)
└── js/
    ├── srs.js          # 에빙하우스 망각 곡선 & SM-2 간격 반복 엔진
    ├── speech.js       # Web Speech API (TTS 발음 재생 및 STT 발음 채점)
    └── app.js          # UI 상호작용, 퀴즈 게임 로직, 상태 저장 컨트롤러
```
